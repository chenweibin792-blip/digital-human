# 数字人互动动作

主页面支持自然语言动作指令和快捷动作按钮。

## 当前动作

| 动作 | 示例指令 | 行为 |
| --- | --- | --- |
| 蹲下 | `请蹲下`、`蹲一下` | 保持蹲下姿态，直到收到站起指令 |
| 站起来 | `请站起来`、`起立` | 恢复站立姿态 |
| 点头 | `点点头` | 播放一次点头动作 |
| 摇头 | `摇摇头` | 播放一次摇头动作 |
| 鞠躬 | `请鞠躬` | 播放一次鞠躬动作 |

纯动作指令不会误发到TTS或大模型。动作与其他内容组合时，会先执行动作，再按
当前“直接朗读”或“AI回答”模式处理完整文字。

## 实现边界

默认Wav2Lip256只生成嘴型，没有人体骨骼、肢体关键点或全身动作生成能力。
当前动作通过浏览器对实时视频进行2D姿态变换，适合即时反馈，但不是新生成的
真实全身画面。

项目原有的 `/set_audiotype` 和 `--customvideo_config` 接口仍然保留。要获得
真实蹲下、挥手、转身等动作，应准备具有合法肖像和使用权的动作视频帧、配套
音频与配置，或通过现有Avatar registry接入支持肢体驱动且许可合适的模型。
